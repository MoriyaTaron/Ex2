Ex2 - Spreadsheet
Description:
The "Ex2" project implements a basic spreadsheet consisting of a 2D array of cells (Cells)capable of calculating values and formulas

File Structure
The project includes the following files:

Cell.java - An interface representing a cell in the spreadsheet.
CellEntry.java - A class implementing the Index2D interface.
Ex2GUI.java - A class implementing the GUI for the spreadsheet.
Ex2Sheet.java - A class implementing the Sheet interface.
Ex2Test.java - A test class for various functions.
Ex2Utils.java - A class containing constants.
Index2D.java - An interface representing a 2D index.
SCell.java - A class implementing the Cell interface.

Usage Instructions
Cell.java - Represents a cell in the spreadsheet with basic functions.
CellEntry.java - Represents an index of a cell in the spreadsheet.
Ex2GUI.java - Implements the GUI for the spreadsheet.
Ex2Sheet.java - Implements the Sheet interface for calculating values and dependency depth, and saving/loading the spreadsheet.
Ex2Test.java - Contains tests for various functions.
Ex2Utils.java - Contains constants for the project.
Index2D.java - An interface representing a 2D index.
SCell.java - Implements the Cell interface and computes formulas.

notes: (:
